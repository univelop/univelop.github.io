Mit dem Schritt _Bestehenden Benutzer hinzufügen_ wird ein bereits existierender Benutzer zum aktuellen Arbeitsbereich hinzugefügt. Der Benutzer muss bereits einen Univelop-Account besitzen.

## Einstellungen

1. **Lizenz** — Der Lizenztyp für den Benutzer im Arbeitsbereich.
2. **ID** — Die Benutzer-ID oder E-Mail-Adresse des hinzuzufügenden Benutzers. Kann als Formel angegeben werden.
3. **Aktive Rolle** — Die Rolle, die dem Benutzer initial zugewiesen wird.
4. **Mögliche Rollen** — Die Rollen, zwischen denen der Benutzer im Arbeitsbereich wechseln kann.

## Hinweise

- Verfügbar in: Geräteseitige Automatisierung, Cloud-Automatisierung, Geschäftsprozess.
