{: .hint }
Die Komponente wird auf dem Homescreen angezeigt.

Im Tab **Komponente** werden nur die Einstellungen der Komponentendarstellung im Arbeitsbereich bearbeitet. Oben wird eine Live-Vorschau der Komponente angezeigt.

1. **Farbe** — Hintergrundfarbe der Komponente auf dem Homescreen. Es stehen nur die Farben des Arbeitsbereichs zur Auswahl.
2. **Indikator** — _Nur bei Einfacher Liste, Gefilterter Liste und Mitglieder._ Wahl zwischen:
   - **Icon** — zeigt nur das gewählte Icon an
   - **Anzahl der Datensätze** — zeigt die Anzahl als Zahl an
   - **Summe** — zeigt die Summe eines Bausteins an; dafür zusätzlich **Summe über** (Baustein-Auswahl) und **Suffix** (z. B. „€")
3. **Komponente verstecken** — Blendet die Komponente für alle Nutzer auf dem Homescreen aus.
4. **Für bestimmte Rollen anzeigen** — Nur sichtbar, wenn die Komponente versteckt ist. Legt fest, welche Benutzerrollen die Komponente trotzdem sehen dürfen.
5. **Bei einzelnem Datensatz direkt zum Datensatz springen** — Überspringt die Listenansicht, wenn nur ein Datensatz vorhanden ist. _Nicht bei Komponenten vom Typ Einstellungen._

{: .hint }
**Name** und **Technischer Name** werden im Tab [Bezeichnungen](/docs/designmode/component/labels) verwaltet, die **Zugeordnete Solution** im Tab [Erweitert](/docs/designmode/component/advanced). **Ordner**, **Duplizieren**, **Exportieren**, **Initialisieren** sowie das Verstecken "nur für mich" stehen ausschließlich im Einstellungs-Panel des [Arbeitsbereich-Designmodus](/docs/designmode/workspace) zur Verfügung, nicht in diesem Tab.
